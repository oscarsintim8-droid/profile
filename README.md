# My Profile (React + Vite)

1. Install Node.js LTS (v20+) from nodejs.org
2. In this folder run:

   npm install
   npm run dev

3. Open http://localhost:5173
4. Edit your details in src/data/profile.js
5. To publish: npm run build, then deploy the dist folder (Netlify Drop) or push to GitHub and import into Vercel.
